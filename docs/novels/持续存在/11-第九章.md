# 错位

神经突触接入的嗡鸣声在颅骨内侧缓缓褪去。

现实中残留的刺鼻消毒水味、胶囊公寓狭窄通道里腐烂的潲水酸气，以及在病房里盗取那个重病孤儿数据时手心渗出的冷汗，在一瞬间被海风吹散。

阿美寮永远是晴天。

阳光穿过海边防风林整齐的针叶，在木栈道上铺满碎金般的斑驳光影。空气里有烘烤过的干草香气与微咸的浪花味，温度精确地恒定在皮肤最舒适的二十四度。这里没有灰尘，没有杂音，没有医院监护仪刺耳的蜂鸣。

成默站在栈道尽头，手指下意识地攥紧裤缝。刚在黑市完成交接的右手还在隐隐痉挛，胃里翻江倒海的干呕感虽然被系统神经滤镜屏蔽了，但那种从骨髓里泛上来的肮脏与冰冷，依然像烙印一样死死贴在胸口。

“哥！”

清脆的声音从木屋拐角处传来。

成诺一路小跑过来，白色的亚麻连衣裙裙摆在风里翻飞。她没有穿鞋，光着脚踩在干燥温暖的木板上，两只细瘦的手臂张开，像一只扑向巢穴的幼鸟，重重撞进成默怀里。

真实的重量、体温，甚至是她发梢上淡淡的柠檬洗发水香气，都精准得令人战栗。

“怎么才来呀？”成诺抬起脸，鼻尖蹭着成默的胸口，眼睛弯成两道明亮的月牙。

成默呼吸一滞，缓缓抬起手，掌心覆在她柔软的头发上。他的动作有些僵硬，喉咙发紧：“……推销跑得有点远，路上耽搁了。”

“我就知道你又没按时吃饭。”成诺拉住他的手，力气比往常大得多，指节几乎要把成默的手指攥出红印。她拽着他往遮阳伞下的白色圆桌走，步子迈得又急又碎，“我今天准备了好多东西！你快坐下，别动，我给你倒红茶。”

她忙碌地在桌边转圈，倒茶、摆盘、拉开椅子。动作流畅得像是一出排练过千百遍的话剧。

但太快了。

成默坐在藤椅上，看着她忙前忙后的背影。成诺以前生病久了，身体弱，即便是在阿美寮里，行动也总是带着一种懒洋洋的迟缓，喜欢赖在椅子里听他说话。可今天，她像是一个上紧了发条的机械木偶，每一秒钟都在拼命释放出“我很好、我很健康、我很开心”的信号。

“哥，你尝尝这个小饼干，我烤的。”成诺把骨瓷碟子推到他面前，眼睛一眨不眨地盯着他的脸，瞳孔里倒映着海面刺目的反光，“你还记不记得？以前在老房子的时候，每到下雨天，妈妈总会把烤箱打开，我们就蹲在旁边看面团鼓起来……”

成默拿起饼干的手指顿了顿。

“还有还有，”成诺根本不给他回答的时间，语速越来越快，胸口微微起伏，“我八岁生日那天，外面下了好大的暴雨，医院的走廊灯坏了，一直在闪。妈妈浑身湿透地推门进来，从雨衣底下拿出了那个戴红帽子的长耳朵兔子玩偶……我当时高兴得一整晚都没睡，一直抱在怀里，对不对？”

她说完，两只手紧紧抓着围裙的边角，身子微微前倾，脸上挂着极度灿烂、甚至有些变形的笑容，急切地等待着成默的确认。

海风还在吹，白色的遮阳伞边缘在风中发出轻微的猎猎声。

成默整个人僵在椅子上。

那个戴红帽子的长耳朵兔子，是他十三岁那年攒了很多天的钱买下的。母亲那天根本没有去医院，母亲当时正忙着和重组家庭的丈夫办出国手续。那天晚上推开无菌仓外隔离门的，是浑身湿透、冻得牙齿打颤的他自己。

成默看着眼前这张天真烂漫的脸。

他的眼神没有责怪，只有一片无法掩饰的空白与骤然下沉的剧痛。

就在成默眼神微变的一瞬间，成诺脸上的笑容彻底凝固了。

那一抹精心维持的光彩像薄冰遭遇滚水，寸寸碎裂。她瞳孔骤然放大，整个人像被抽空了骨架一样，不受控制地颤抖起来。

“我……我说错了，是不是？”她的声音抖得不成样子，刚才的热情与明媚荡然无存。

“成诺……”成默想要伸手去拉她。

“扑通”一声。

成诺没有后退，而是双膝一软，直接坐倒在木栈道上。

木板发出沉闷的撞击声。她瘦弱的身躯缩成极小的一团，两只手抱着自己的双腿。她仰起头，眼泪毫无预兆地大颗大颗砸落下来，砸在自己的鞋面。

“对不起……哥，对不起……我记错了，我不是故意的……”

她哭得喘不上气，喉咙里发出呜咽，整个人抖得像狂风中的枯叶。

“我刚才……我脑子里有两个画面，我不知道哪一个是真的……我以为是妈妈送的……对不起，我再记一遍，我马上就能改过来！是你送的，是哥送给我的红帽子兔子，我喜欢它，我真的记得它！”

她语无伦次地仰着脸，眼底深处没有对过去的怀念，只有漫无边际的恐慌。

那不是一个任性妹妹在向兄长撒娇。

那是一个觉察到自己是一具空壳、一串借用了死者残存影子的意识，在发现自己露出了破绽后，对被抛弃所产生的滔天恐惧。

她早就发现了那些接缝。那些不属于自己的记忆，那些偶尔在意识深处浮现的空白断层。她知道了可能自己不是那个真正死在无菌仓里的女孩。

可她唯一拥有的全部世界，就是眼前这个叫她“妹妹”的人。

“求求你……哥，求你别走……”成诺把额头死死抵在自己的膝盖上，肩膀抖动，眼泪浸透了成默的裤管，“别不要我……我很乖的，我会好好学的，我下一次一定不会记错……你别不来，求求你，别把我关掉……”

阿美寮的海滩依然明亮如洗。

海鸥在蔚蓝的天际盘旋，海浪一遍遍温柔地冲刷着金黄色的细沙。世界美好得如同一座永不褪色的水晶温室，而温室的中心，两个人在温暖的阳光下跪倒在一起，痛哭失声。

成默缓缓蹲下身，伸出那双刚刚在现实里犯下不可饶恕之罪的手，用力将地上的女孩拉进怀里。

他抱得那么紧，骨节泛白，仿佛只要一松手，怀里这个拼命想要证明自己存在的新生灵魂，就会随同他残存的人性一起，被风吹散在大海尽头。

他一句话也说不出来，只是把脸埋在她的颈窝，任由滚烫的眼泪淌过彼此冰冷的皮肤。

阳光落在他们身上，尚有一丝温度。
