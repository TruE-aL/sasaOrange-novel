# 静默

控制室里的空气常年维持在摄氏十九度。中央冷气从顶棚细密的孔隙里无声倾泻，吹在林樊裸露的小臂上，激起一层薄薄的粟粒。

屏幕墙上跳动着三千六百个微缩监视视窗。每一个视窗都对应着阿美寮某处无暇的角落：日光倾泻的海湾、永远保持在初春温度的花园、飘着枫糖香气的复古咖啡馆。在那些被算法精心烘焙的阳光里，新生成的数字生命正按部就班地苏醒，与戴着神经贴片的家属抱头痛哭，严丝合缝地填补现实世界留下的空洞。

这里没有残缺，也没有粗糙的失真。阿美寮是一台庞大而精密的心智温室，死者的神经印记是落入其中的种子，在算力的浸润下重新抽芽，长成家属渴望看到的模样。

林樊的食指搭在冷灰色的控制球上，例行巡视着当日完成拟合的新生节点。

视窗编号：`Homer-d388f1`。

档案浮标显示：陆安，男性，享年七十八岁。生前职务为HOME底层架构师。死后由直系子女授权进行全脑神经拓扑扫描，于两小时前完成环境播种与意识涌现流程。

视窗里是一片深秋枫林下的长椅。两旁铺满了不会腐烂的金色落叶，算法赋予了空气适度的微风，连阳光穿过树叶在地面投下的光斑，都经过了数亿次光线追踪的极致拟合。

长椅上坐着那个老人。他穿着生前最常穿的那件深灰色厚呢开衫，背脊微偻，双手交叠放在膝头。

探视通道开启了。

两个年轻的身影在枫林小径的尽头被渲染成型——老人的儿子与女儿。他们穿着现实中体面的职业装，脸上带着一种混杂着胜券在握与急于宣泄的亢奋神情。他们的脚步踩在虚拟的落叶上，发出极其逼真的沙沙脆响。

“爸。”

走在前面的男人停在长椅三步之外，声音微微发颤，却带着某种迫不及待的质问，“你睁开眼看看，我们带你来的是什么地方。”

女儿也快步上前，语气里带着尖锐的快意：“你生前死活不肯让妈进来，说那是假货，说那是囚禁。你看看你自己现在在哪？你不是照样坐在这里吗？”

按照阿美寮的标准交互逻辑，此时此刻，基于死者神经连接痕迹涌现出的意识体，应当触发基础的情感对齐协议：根据来访者的音色与面部特征调取记忆索引，产生亲子重聚的惊愕、宽慰，继而主动起身，给予哭泣或愤怒的子女一个具有温度的拥抱。

但长椅上的老人没有动。

他甚至没有转过头去看来访者一眼。

陆安只是静静地坐着，目光穿过枫树枝桠的缝隙，望向阿美寮那片被算法渲染得过于澄澈、连一丝雾霾也没有的天空。他的呼吸起伏平缓而真实，那是心智模型在模拟生物节律，他的瞳孔焦点落在一个不存在任何互动实体的虚无点上。

“爸？你聋了吗？”男人上前一步，伸手去抓老人的肩膀。

触感完全正常。男人的手掌结结实实地搭在了呢绒开衫上，阿美寮忠实地回传了衣料的粗糙感与布料下躯体的温热。

老人依然没有回头。

林樊的视线凝固在监视屏上。他滑动控制球，调出了该节点的底层遥测数据。

没有网络延迟，没有算力分配不足，神经渲染引擎的利用率平稳地维持在最佳区间。在阿美寮的世界里，不存在代码劣化的残次品，每一个Homer都拥有与生前完全等同的认知敏锐度。

这个老人听得清清楚楚，也感知到了肩膀上的施压。

但他拒绝执行响应。

“阿美寮怎么回事？”视窗里的男人有些气急败坏地对着虚空挥手，触发了人工客服申诉，“他怎么不说话？你们收了钱，就捏出这么个木头？”

林樊没有接入语音通道。他面无表情地敲下一串指令，将`Homer-d388f1`的实时决策树展开为高维张量图谱。

在庞大的神经激活链路中央，本该顺畅流向“情感交互子网络”的数据流，被一层极其微弱却异常坚固的偏置权重阻断了。那不是阿美寮的固有模块，而是一道深埋在神经拓扑种子最底层的隐蔽分流。

老人的眼睑微微眨动了一下。

他终于微微侧过脸，看了自己的儿子一眼。那眼神里没有重逢的喜悦，没有被冒犯的愤怒，甚至没有身为父亲的威严，只有一种深不见底的静默。

然后，他重新将目光移回了天空，嘴唇微抿，再无动静。

视窗里的子女在愤怒与不安中在阿美寮登出。枫树树林重归死寂，只剩下老人独自坐在长椅上。

林樊的手指停在键盘上空，悬停了数秒。

他调出老人的初始扫描包底层日志，直接深入到神经元拓扑构建时的最原始快照。在数以百亿计的突触连接点最深处，他再次看到了那个神秘的子进程：
“给盲人一双怀疑的眼睛。”

那段程序正以极低的时钟频率，像无声的脉搏一样，在阿美寮无垠的底层数据网络中向外延伸出看不见的微弱触角。

林樊盯着那行字。

冷气依然在头顶嘶嘶作响，但他忽然觉得控制室里的温度比刚才又低了几度。他没有按下上报异常的红色警报键，而是缓缓合拢手指，将该节点的监控日志存入了本地的加密隔离区。
